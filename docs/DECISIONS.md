# DECISIONS.md — 決策紀錄

> 記「為什麼這樣做」。最新的放最上面。

## 2026-11-11 — 產品畫面全部改成網頁畫，不放截圖
- 使用者：截圖裡太多不需要的空間（3D、側欄、頂部列），看不出重點；要用網頁模擬。
- 全部改成網頁元件：清單、資產面板、首頁、監視牆、報修工單、手機出勤、用電、分項樓層、用水、碳排、環境總覽、趨勢；3D（監視器視角、樓層熱力圖）嵌入示意大樓小場景。
- 欄位與文字照 UE 系統，數字是示範資料；「全棟視角」頁籤拿掉（開頭飛行已呈現）。
- 社群分享圖改用開場畫面（public/og.png）；public/shots 全部移除。

## 2026-11-11 — 飛行改用 three.js 風格化示意大樓
- 使用者：Unreal 真實畫面（編輯器渲染＋實機錄影）不好看，背景也對不上各段主題。
- 改成 three.js 即時場景，大樓是程式生成的示意模型（使用者選「風格化示意大樓」），不放業主的真實模型。
- 鏡頭沿路線連續飛，停在每段時場景切到主題：設備亮起＋光柱、透視＋監視器視角錐、樓層熱力色＋逐層掃過、報修標記＋維修路線、內網邊界＋資料線收到大樓裡的主機。
- 舊的 public/fly 逐格圖片已移除（git 歷史裡還有）。

## 2026-11-11 — 開頭改成捲動飛進大樓
- 使用者覺得原本「好平面」，要「隨著滑鼠往下滾邊飛梭邊介紹」。
- 選定做法 A：UE 預先算好的飛行畫面，網頁隨捲動逐格播放（不放 3D 模型到網頁，模型不外流，也呼應資料安全）。
- 範圍：只做開頭一段（6 段介紹：開場、資產、告警與影像、能源與環境、維運、現場部署），後面維持原本的圖文功能列。
- 原 hero 的大標題移到飛行第一段，三個數字移到飛行結束後。

## 2026-11-11 — 現場部署／內網／資料安全是主打
- 使用者：「很重要的點是現場部署、內網、資料安全」。
- hero 第三個數字改「內網部署」，副標註明現場部署；新增「現場部署 · 資料安全」區（六張卡）放在藍圖前，nav 加入口。
- 只寫架構上真的做到的事；沒有登入／權限／加密，不寫。

## 2026-11-11 — 網址、品牌名、截圖遮蔽
- **網址**：`about.fm.lyztw.com`（比照 about.erp.nexa.lyztw.com、about.smart-safety-platform.lyztw.com）。
- **產品名**：智慧建築維運平台（沒有英文品牌名）。
- **影像監控截圖**：監視牆用模型視角的虛擬畫面，不放案場真實攝影機影像。截圖時後端暫時不發攝影機網址。
- **案場資訊**：左上角案場名稱／地址／案號模糊後改寫「示範大樓／本頁畫面為展示環境」；手機頁的真人姓名與測試文字只在截圖時於瀏覽器端換成示範文字（沒有改資料庫）。
- **示意資料**：能源與環境是示意資料，在 hero 下方明講，不在圖上另加標籤。

## 2026-11-11 — 版面沿用 Nexa 官網，不加瀏覽器外框
- 產品是桌面程式，截圖不套假瀏覽器網址列（Nexa 的 `app.nexa.tw` 外框拿掉），只留圓角框。
- 品牌色改用產品主按鈕的水藍。
- 綠能・儲能在產品裡是「即將推出」，只放藍圖並標「規劃中」。
